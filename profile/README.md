## 🌱 우리가 하는 일

**ECOLEAD**는 친환경 건축물 인증과 에너지 컨설팅을 전문으로 하는 기업입니다.
건물의 기획 단계부터 준공 이후 성능 검증까지, 데이터 기반으로 지속가능한 건축을 설계합니다.

| 분야 | 내용 |
|---|---|
| 🏅 **LEED 계획 및 인증** | 미국 친환경 건축물 인증(LEED) 컨설팅 — 등급 목표 설정, 크레딧 전략, 인증 취득 |
| 🏢 **국내 건축물 인증** | G-SEED(녹색건축), 건축물 에너지효율등급, 제로에너지건축물 등 국내 인증 대응 |
| ⚡ **에너지 분석 및 커미셔닝** | 에너지 시뮬레이션, 절감율 분석, 설비 성능 검증(Cx) |
| 🔍 **건축물 기밀성능평가** | Blower Door Test 기반 기밀성능 측정 및 평가 |
