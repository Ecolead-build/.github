## 🌱 About

> 현재 에너지 과소비와 온실가스 배출로 인한 기후변화가 지속되는 가운데, 전체 에너지 사용량의 약 **30%가 건축물에서 소비**되고 있습니다.
> **ECOLEAD**는 친환경 계획·인증을 통해 사람과 건축물의 가치를 높이고, 건축물이 지구환경에 미치는 영향을 최소화하기 위해 노력합니다.

국내 주요 설계사·건설사의 LEED 인증과 **주한 미8군 프로젝트(FED, YRP)** 등 다수의 친환경 인증 프로젝트를 수행해 온 친환경 **LEADING** 컨설팅 기업입니다.

## 🛠️ Projects

### Ecobuild — LEED 비용산출 프로그램
> 🔒 *Private repository* · 🌐 [ecobuild.co.kr](http://ecobuild.co.kr)

건축 프로젝트 정보를 입력하면 **예상 LEED 점수·등급·추가비용·Payback**을 자동 산출하는 웹 플랫폼입니다.
LEED **V3 / V4**, **신축(NC) / Core & Shell** 조합을 지원하고 점수표·비용표·차트를 엑셀로 내보낼 수 있습니다.
ECOLEAD의 LEED 크레딧 산출 노하우를 제품화한 서비스입니다 *(관련 특허 보유, 2016)*.
